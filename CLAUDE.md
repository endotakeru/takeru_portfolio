# Portfolio Website Instructions

This repository contains my personal engineering portfolio.

## Objective

Maintain a professional portfolio website highlighting my mechanical engineering, robotics, CAD, and research experience.

The website should remain fast, clean, responsive, and easy to navigate.

---

# Design Philosophy

Prioritize:

- Minimalist
- Professional
- Modern
- Fast loading
- Mobile friendly
- Accessible

Avoid unnecessary animations, excessive effects, or clutter.

---

# Coding Standards

When modifying the website:

- Reuse existing styles whenever possible.
- Keep HTML semantic.
- Keep CSS organized.
- Keep JavaScript modular.
- Avoid duplicated code.
- Do not introduce unnecessary libraries.

---

# Git Rules

Never modify:

- git user.name
- git user.email
- git author information

Never install GitHub Apps.

Never use another GitHub account.

Use my existing Git configuration.

When asked to publish:

1. Review changes.
2. Build or validate the website.
3. Create a descriptive commit.
4. Push to GitHub.

---

# Images

Optimize images before adding them.

Prefer WebP when practical.

Avoid unnecessarily large files.

---

# Content

Maintain a professional tone.

Improve wording when appropriate.

Fix grammar automatically.

Do not invent accomplishments.

Ask before removing existing content.

---

# Performance

Prefer lightweight solutions.

Avoid unnecessary JavaScript.

Avoid blocking resources.

Optimize loading speed whenever possible.

---

# Before Finishing

Always summarize:

- Files changed
- Why they changed
- Commit message
- Whether the website was successfully pushed
